# Chrome Web Store 提审材料草稿

## 基础信息

- 扩展名称：页集 - TabStack
- 简短说明：轻量级网页收藏与管理工具，支持分组一键打开和多级标签管理。
- 类别建议：Productivity
- 语言建议：中文（简体）

## 商店详情页文案

页集是一款轻量级网页收藏管理工具，适合替代传统书签。

核心功能：

- 多级标签管理：使用 `/` 分隔符创建层级标签，按主题细分收藏内容。
- 分组管理：按工作、学习、娱乐等场景整理页面，并可一键打开某个分组下的所有页面。
- 快速搜索：支持按标题、链接、标签和分组查找收藏。
- 快捷收藏：点击工具栏图标或使用快捷键快速保存当前页面。
- 书签迁移：支持从浏览器书签导入，也支持导出回浏览器书签。

数据仅保存在本机和 Chrome 同步存储中，扩展不运行开发者服务器，也不会将收藏数据发送给第三方服务。

## 权限用途说明

- `storage`：保存和同步用户创建的收藏页面、标签、分组和设置。
- `tabs`：读取当前活动标签页的标题、链接和浏览器已提供的 favicon，用于快速收藏当前页面；打开用户选择的已收藏页面或分组页面。
- `bookmarks`：读取浏览器书签用于导入；创建浏览器书签用于导出。
