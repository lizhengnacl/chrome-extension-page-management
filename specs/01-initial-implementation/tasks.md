## 风险与注意事项

1. **书签导入/导出**: chrome.bookmarks API 的权限和行为需要充分测试
2. **自动更新**: 避免对用户造成过多网络请求
3. **拖拽排序**: 确保在不同屏幕尺寸下体验一致
4. **存储容量**: 大量数据导入时要监测存储用量
